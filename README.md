## What it does

`main.py` writes a single one-line warning label for a time machine to
`/output/entry.txt` (84 characters, inside the 1–120 character gate).

## The entry

> WARNING: Do not kill your grandfather. HR has already processed his complaint twice.

Why this line: the grandfather paradox (a real hazard of time travel)
turned into a deadpan HR joke, the punchline saved for the last words,
phrased like a genuine safety notice, with no wasted words — matching the
judge brief's five criteria in order.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
